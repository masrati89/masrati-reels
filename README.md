# masrati-reels

מערכת להפקת רילסים של מסרטי הנדסה: ליקוי מהשטח הופך לסרטון אנכי ממותג (1080×1920).

## מבנה
- `template/` – רכיבים קבועים: סקריפט רינדור, גופני Rubik ו-Heebo, לוגו.
- `reels/NN-name/` – סרטון לכל ליקוי: קובץ הסצנות (reel.html) וטקסט הקריינות.
- מדיה (תמונות, קליפים, שמע, סרטון מוגמר) לא נשמרת כאן. היא נמצאת ב-Drive של masratieng@gmail.com, בתיקייה שיווק/רילס.

## תהליך
1. חיים מכניס ל-Drive (רילס/01 - חדש) תמונות, קליפ ונוסח הליקוי מהדוח.
2. Claude מכין תסריט (מלל על המסך, קריינות, סימונים) ושם ב-"02 - ממתין לאישור".
3. חיים מאשר, ומפיק קריינות ב-ElevenLabs (קול Itamar, "Masratti הנדסה", "רוֹבָּה").
4. Claude מסנכרן את הסצנות לשקטים בהקלטה, מרנדר ומעלה ל-"03 - מוכן לפרסום".

## רינדור
דורש Node, Playwright (Chromium) ו-ffmpeg.
```
node render.js all            # מרנדר פריימים לתיקייה frames/
ffmpeg -framerate 30 -i frames/%04d.jpg -i vo.mp3 -c:v libx264 -crf 18 -pix_fmt yuv420p -c:a aac out.mp4
```

## כללי תוכן
- מבנה הסרטון לפי מבנה הממצא בדוח: הוק, מה נצפה, מדידה, כרטיס תקן (תקן/סעיף/הגדרה), השלכות בניסוח מותנה ("עלול"), סגירה, כרטיס סיום.
- כל תקן, סעיף או ערך מגיע מחיים. לא ממציאים.
- עיצוב לפי ספר המותג: כחול #0D2949, פליז #AA8A53, קרם #F6F1E6. כותרות Rubik, טקסט רץ Liberation Sans. פריסה א-סימטרית, טקסט מיושר לימין.

## מצב
- סרטון 01 (שיפוע מקלחון) הושלם. הסצנות עדיין כתובות ישירות ב-reel.html.
- הבא: הפרדת הסצנות לקובץ תסריט (JSON), כך שכל סרטון חדש הוא תסריט חדש על אותה תבנית.
